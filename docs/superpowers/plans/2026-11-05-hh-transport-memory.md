# HH transport and memory repair

**Goal:** устранить потерю первичной квитанции и аварийное исчерпание heap browser.
**Scope:** пользователь поручил исправления, публикацию GitHub, оба VPS,
обновление MD и длительную проверку; личные scope/согласия/ledger сохраняются.
**Design:** единственный строго проверенный запрос отправляется через route.fetch
без redirect/retry; только исходный APIResponse доказывает отправку, synthetic
ответ браузеру доказательством не является. APIResponse освобождается finally.
Для памяти сначала воспроизвести рост и связать его с удерживаемыми объектами;
числовая диагностика не должна содержать HH payload или секреты. Увеличение
лимита само по себе не доказывает исправление утечки.
