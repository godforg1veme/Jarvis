# Ремонт native XHR капчи HH

**Цель:** принимать наблюдавшийся native XHR только с проверенными параметрами
текущей формы и картинки, сохранив одну попытку и запрет повтора неизвестного POST.

**Контракт:** [проверки запроса](../specs/2026-10-16-hh-native-captcha-request-design.md).
**Стек:** CommonJS, Playwright 1.64, существующие Chromium/HTTPS fixtures.

- [x] Проверить фактический запрос без передачи ответа HH и сохранить только
  безопасные признаки связи с формой/картинкой.
- [x] Проверить ветки/worktrees/PR; начать отдельную короткую ветку.
- [x] Добавить закрытый query-контракт в `captchaProtocol.js`; сохранить body-контракт.
- [x] В `captchaRecovery.js` связать запрос с ключом выбранного изображения,
  recheck source после OCR; передавать только нужные metadata запроса.
- [x] Проверить отказ при подмене полей, CSRF, body, transport, origin и duplicates.
- [x] Расширить Chromium/HTTPS fixtures на оба формата: cookies, одна отправка,
  tampering, restart, foreign owner, потеря ответа и запрет redirects.
- [x] Завершить изолированные Linux проверки и записать результат, включая
