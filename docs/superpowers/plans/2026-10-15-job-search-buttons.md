# Job search buttons implementation plan

**Goal:** Выполнить прямое поручение владельца: включение/выключение поиска
кнопками и постоянный пункт поиска работы в нижнем меню Telegram.

**Design:** «💼 Поиск работы» добавляется отдельной строкой владельцу в личном
чате при включённой функции. Открывает существующий `job:menu` и завершает
незавершённый guided input. В разделе показывается «Включить поиск» либо
«Выключить поиск» по фактическому состоянию. Используются существующие
`job:resume` / `job:pause`, без новых callback/kind/migrations. Нажатие задаёт
явное состояние, сохраняет фильтры/checkpoint/progress и отзывает старый lease.
Отправка отклика сохраняет прежнее отдельное подтверждение точного письма.

**Scope:** `telegramMenu.js`, `telegramMenuService.js`, `jobTelegramViews.js`,
`jobTelegramService.js`, `jobSearchRepository.js`, контракт и профильные тесты.
Без новых зависимостей, Desktop и автоматического включения до нажатия владельца.

- [x] Добавить клавиатуру и маршрут, сохранив feature-off и owner/private guards.
- [x] Добавить явный идемпотентный switch с сохранением прогресса.
- [x] Проверить реальные message/menu handlers + PG: выход из ввода настроек,
  первый запуск, повторный update, остановка, запрещённые user/chat и старый lease.
- [x] Обновить контракт меню; выполнить Telegram gate, full server и PG acceptance.
- [x] Сохранить локальный результат и предложить server-only выпуск для Telegram.
