# Живой фон Operations UI

Пользователь 22 октября выбрал анимацию в интерфейсе: медленный полёт через
космос с глубиной, мягким мерцанием и сохранением принятого оформления.

Единственный SharedSky остаётся за сценой и прозрачным сайдбаром. Существующая
узкая текстура Млечного Пути получает заметное за несколько секунд плавное
смещение, без скачка на повторе. Поверх неё один прозрачный Canvas 2D рисует
три слоя звёзд и редкие ближние частицы с разной скоростью. Слабое локальное
свечение добавляет глубину, не меняя тёмную палитру. Существующие редкие события
и геометрия планет сохраняются.

Не добавляем зависимости, видео, новые сетевые ресурсы, обработку курсора или
новые настройки. Пауза, reduced motion, скрытая вкладка и fallback 3D
останавливают движение; продолжение не перескакивает вперёд. На паузе кадр
сохраняется, при изменении размера остаётся тот же узор. Canvas ограничен
30 обновлениями в секунду, DPR <= 1.5 и меньшим числом частиц на телефоне.
Движение видно также через сайдбар и не зависит от выбранной планеты.

Приёмка: unit-проверки остановки/продолжения/cleanup, build, реальные браузерные
кадры через несколько секунд на широком и узком экране, отсутствие overflow,
проверка reduced motion и fallback без картинки. Измерение браузера не заменяет
замер FPS на физическом телефоне. Этап локальный; выпуск обсуждается после
просмотра результата.

## Уточнения пользователя после просмотра

Движение всех слоёв ускорено вдвое, скорости планет сохранены. Последующий
запрос требует настоящих деталей 4K и более спокойного фона. Прежнюю текстуру
заменяет NASA/Gaia Milky Way без ярких звёзд переднего плана: источник 8192×4096,
WebP 4096×2048/8192×4096 без апскейла. CSS сохраняет монохромную диагональную
композицию и 28-секундный ход; отдельный Canvas рисует чёткие звёзды. Responsive
sizes учитывает object-fit и масштаб, 8K при ошибке заменяется 4K. Кадрирование
проверяется на UHD, ultrawide и телефоне, включая reduced motion.
