## Ранее отправленные карточки

Одноразовая операция обрабатывает сохранённые delivery message IDs только
настроенного owner в его private Telegram chat. На старте найдено 260 карточек,
для всех revision исходной вакансии равна 1. Используется прежний renderer
текста/кнопок; меняется параметр предпросмотра. Успешный ответ Telegram проверяется
по chat/message ID и тексту, отдельно учитывается `is_disabled=true`.
План и результаты сохраняются приватно вне Git; неизвестный ответ не запускает
операцию с новым ID. Удалений, пересылок и повторной рассылки нет.

Операция завершилась с кодом 0: обработаны все 260 карточек, из них 256
изменены с подтверждённым `is_disabled=true`, ещё 4 уже имели нужное состояние
(Telegram вернул message is not modified). Неразрешённых результатов и ошибок
нет. Checkpoint имеет права 0600. Новые сообщения доставляются исправленным
runtime; оставшиеся четыре карточки дополнительно подтвердили это поведение.
