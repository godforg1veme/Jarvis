# Компактные сообщения поиска работы

15 октября 2026. По снимку владельца: Telegram разворачивал HH URL в крупный
предпросмотр с картинкой. Подготовлено локальное исправление; на VPS оно ещё
не установлено.

Сообщения домена поиска работы помечаются для отключения link preview.
Параметр передаётся как в автоматической доставке через настоящий runtime
`sendMessage`, так и в ответах на кнопки. При разбиении длинного письма
предпросмотр отключён для каждой части. Ссылка остаётся кликабельной;
кнопка открытия вакансии и остальные действия сохраняются. Старые сообщения
не удаляются и не редактируются; изменение применяется к новым сообщениям.

Используется [LinkPreviewOptions Telegram](https://core.telegram.org/bots/api#linkpreviewoptions),
без дополнительных запросов или зависимостей. Остальные разделы бота,
подтверждение откликов, владелец и scope не меняются.

Проверки: фактические параметры доставки карточки и ручного ответа через
полный runtime, настоящие PG/grammy handlers и транспорт с подставным Bot API;
кликабельная кнопка сохранена. Отдельно проверено отсутствие preview на всех
частях длинного письма. Результат не заменяет визуальную проверку нового
сообщения после установки обновления на DE.
