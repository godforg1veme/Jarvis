# Кнопки включения поиска и нижнее меню

15 октября 2026. Владелец явно поручил включение/выключение кнопками и постоянный
пункт поиска работы в нижнем меню. После отдельного разрешения на выгрузку
изменения опубликованы в GitHub main и установлены на DE. Этот результат
обновляет интерфейс [первого выпуска](2026-10-15-job-search-release.md).

Добавлена «💼 Поиск работы» отдельной строкой нижней клавиатуры владельца
в личном чате при включённой функции. Пункт открывает существующий job menu
и закрывает незавершённый ввод настроек. Чужой пользователь и группа доступа
не получают; при feature-off новая кнопка не показывается.

В начале раздела находится «Включить поиск», если он выключен, либо
«Выключить поиск», если работает. Нажатие задаёт явное состояние, а повтор
не переключает его обратно. Сохраняются фильтры, checkpoint и незавершённый
прогресс; старый lease отзывается, поэтому остановленный сборщик не сможет
перезаписать сохранённое состояние. После включения проверка доступна сразу.
Отправка откликов по-прежнему требует отдельного подтверждения точного письма.
Новые callbacks, guided-input kinds, migrations и зависимости не добавлялись.

Проверены реальные message/menu handlers с PostgreSQL: навигация из ввода,
первый запуск, duplicate update, повтор enable/disable, отказ чужому user/chat,
сохранение прогресса и отзыв старого lease. Full server: 627/627;
Telegram gate: 65/65; PG acceptance: 13/13; полный runtime с 32 миграциями: 1/1.
Настоящие нажатия в Telegram после обновления сервера ещё не выполнены.

## Выпуск

Server runtime: `31512060b11c0f92c8963250c5bc179e9645e8e2`, отдельный release
`/home/deploy/releases/jarvis-31512060-job-buttons`. Готовый server image также
прошёл 627/627 тестов. Окружение сохранено полностью, secret bind mounts
сохранили inode, предыдущий image оставлен для возврата.

Обновлён только server. Browser, collector, PostgreSQL, ASR и tunnel сохранили
container ID и работают; Desktop не менялся. GitHub, Windows и исходники обоих
VPS совпали; release-status без issues. Server healthy, внутренний ready и
публичный smoke прошли. Последующие изменения документации не требуют rebuild.

В работающем коде проверены нижняя клавиатура, валидность inline-кнопок и
соответствие фактическому состоянию: поиск уже включён, показывается
«Выключить поиск». Состояние не менялось при выпуске. Сборщик находится в
collecting без failure code, в очереди уже есть успешно отправленные доставки.
Рендеринг на сервере не заменяет нажатие владельцем в настоящем Telegram.

Для проверки на рабочем боте выполнен server-only выпуск по release-workflow
с синхронизацией GitHub и обоих VPS source. Browser/collector, HH volume,
настройки поиска, скрытые работодатели и Desktop не менялись.
Существующий Telegram-клиент получит новую клавиатуру после `/start`
или «🏠 Главное»; нажимать включение вместо владельца при выпуске не нужно.
