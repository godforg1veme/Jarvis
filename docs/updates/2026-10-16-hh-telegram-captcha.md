# Капча HH через ответ на фото в Telegram

16 октября 2026. Владелец согласовал сценарий и поручил публикацию в GitHub,
установку на VPS и удаление Tailscale-компонентов именно для HH.
[Проект](../superpowers/specs/2026-10-16-hh-telegram-captcha-design.md),
[план](../superpowers/plans/2026-10-16-hh-telegram-captcha.md).

## Поведение

При капче сбор приостанавливается. Бот присылает только изображение капчи.
Владелец выбирает «Ответить» на фото и пишет два слова. Этот ответ разрешает
одну отправку формы HH. После проверки доступа поиск продолжает прежний прогресс.
Кнопка «Обновить картинку» запрашивает другую капчу. Картинка действует 10 минут;
пауза сохраняется до успешной проверки.

Ответ не попадает в диалог, память, модель или логи. Привязка проверяет владельца,
личный чат, conversation, message ID, challenge и revision. До отправки сохраняется
факт расходования ответа. Неопределённый результат автоматически не повторяется.

Удалены HH gateway, noVNC, display/VNC runtime, host proxy и соответствующие
настройки, зависимости и тесты. Закрытый broker работает в прежней приватной
Docker-сети без host port. Общий Tailscale, его другие маршруты и VPN сохраняются.

## Проверки до установки

- Server: 633/633; обязательный Telegram gate: 65/65; отдельные unit/HTTP: 5/5.
- Настоящий изолированный PostgreSQL: 4/4, включая повтор, чужой scope,
  неизвестную доставку и явное обновление картинки.
- Linux browser: 37/37, ещё три runtime случая и семь Chromium regression случаев.
  Настоящий HTTPS стенд подтверждает один POST, запрет повторов и точную проверку
  target. Telegram режим не запускает прежний OCR даже при старом OCR flag.
- Политика Compose: 4/4; нормализованные конфигурации с выключенным и включённым
  режимом проверены. Новых production-зависимостей нет.

## Установка и живая приёмка

Код опубликован в GitHub main: `b0712e69875adbe62db1892007da65f34d4d636f`.
Windows и оба VPS получили эту версию. На DE server/browser/collector установлены
из отдельного immutable release с тем же SHA. Исходники внутри контейнеров,
image IDs, health, отсутствие host ports и распределение credentials проверены.
Migration 032 применена. На NL обновлены исходники; поиск там не запускался.

Профиль HH сохранил прежние inode и права; настройки и смонтированные секреты
сохранены. Остальные контейнеры не пересоздавались. Удалены старый HH gateway,
пустая dedicated network, HH systemd socket/service/launcher и Serve `/hh/` на443.
Общий Tailscale остался online, прежний HTTPS10000 `/` и другие настройки сохранены.
Подготовительная проверка абсолютного Compose secret target сначала остановила
staging до изменения служб; путь исправлен, фактические inode повторно сверены.

До перехода сбор уже возобновился. К установке возникла очередная CAPTCHA;
новый worker отправил настоящее фото в Telegram и сохранил message binding.
Проверка после установки: broker active, ручная пауза, lease отсутствует,
583 отправленные карточки, 48 оставшихся запросов, текущая страница 15.
Намеренно новую капчу не вызывали, answer POST от агента не отправлялся.

Настоящий ответ владельца на Telegram-фото и последующее возобновление пока
ожидаются. Отправку откликов этот выпуск не проверяет. Desktop не менялся
и не требует пересборки. Последующие MD-коммиты не требуют рестарта контейнеров.
