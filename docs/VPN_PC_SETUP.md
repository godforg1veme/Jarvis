# Настройка VPN на ПК (Windows и macOS) — Jarvis

В инфраструктуре Jarvis развернуто два независимых протокола:
1. **Hysteria 2 (Основной, высокоскоростной):** работает по UDP/QUIC через порт 443 с маскировкой Salamander. Обеспечивает минимальный пинг, высокую скорость в играх и устойчивость к блокировкам.
2. **VLESS + REALITY (Резервный):** работает по TCP через порт 8443/443 с маскировкой под TLS-трафик браузера Chrome. Идеален, если сеть или провайдер глушит UDP.

> **Частая ошибка с v2rayN:**
> Стандартный v2rayN использует ядро **Xray-core**, которое в принципе **не поддерживает протокол Hysteria 2 (`hy2://`)**.
> Если вы вставите ключ Hysteria 2 в v2rayN, тест задержки выдаст **`n/a`** или ошибку конфигурации!
> Для v2rayN используйте **VLESS**-ключ (`vless://`), либо для Hysteria 2 установите **Hiddify** или **Happ Desktop**.

## 2. Пошаговая настройка Hysteria 2 (Hiddify / Happ)

### Вариант А: Через Hiddify (самый простой и надежный вариант)

1. **Скачайте Hiddify:**
   Перейдите в [релизы Hiddify](https://github.com/hiddify/hiddify-next/releases) и скачайте установщик для Windows (`Hiddify-Windows-Setup-x64.exe`).
2. **Установите и запустите:**
   Установите программу. В Windows запустите её **от имени Администратора** (требуется для TUN-режима).
3. **Получите ключ:**
   В Telegram-боте Jarvis откройте `/vpn` → выберите **«⚡ Hysteria2 — рекомендуется»** → **«👥 Мои доступы»** → нажмите на ключ `hy2://...` для копирования.
4. **Добавьте профиль:**
   В окне Hiddify нажмите кнопку **«+ Новый профиль»** → выберите **«Добавить из буфера обмена»** (или нажмите `Ctrl+V`).
5. **Включите VPN:**
   - Включите переключатель **Режим TUN** (в нижнем или боковом меню).
   - Нажмите большую круглую кнопку подключения в центре.
   - Готово! Весь трафик компьютера защищён и идёт через ваш сервер.

### Вариант Б: Через Happ Desktop

1. Скачайте Happ Desktop с [happ.su](https://happ.su).
2. Запустите установщик. Обязательно подтвердите запрос прав Администратора.
3. Скопируйте ключ `hy2://...` из бота.
4. В Happ нажмите **«+»** вверху справа → **«Импорт из буфера обмена»**.
5. Нажмите переключатель подключения.

## 3. Пошаговая настройка VLESS Reality (v2rayN)

Если вам удобнее использовать классический v2rayN:

1. **Скачайте v2rayN:**
   Скачайте архив `v2rayN-with-core.zip` из [релизов v2rayN](https://github.com/2dust/v2rayN/releases). Распакуйте в отдельную папку (например, `C:\Tools\v2rayN`).
2. **Получите VLESS-ключ:**
   В Telegram-боте Jarvis откройте `/vpn` → выберите **«🛡 VLESS — резерв»** → **«👥 Мои доступы»** → скопируйте ключ `vless://...`.
3. **Импортируйте:**
   Откройте v2rayN и нажмите комбинацию клавиш `Ctrl+V`. Сервер появится в списке.
4. **Активируйте:**
   - Выделите добавленный сервер и нажмите `Enter` (он станет синим/активным).
   - Внизу окна в выпадающем меню «Системный прокси» выберите **«Автоматически настраивать системный прокси»** (или включите переключатель **«Включить режим TUN»** для проксирования игр и всех приложений).
5. **Проверьте:**
   Нажмите `Ctrl+R` — в колонке задержки отобразится реальный пинг.

## 4. Почему на ПК пишет «Пинг n/a» и как это исправить

Если на смартфоне VPN работает, а на ПК пинг показывает `n/a` или таймаут, проверьте 5 основных причин:

### 1. Несовместимость клиента и протокола (Hysteria 2 в v2rayN)
- **Симптом:** Вставили ключ `hy2://` в v2rayN, нажимаете тест — пинг `n/a` или `failed`.
- **Причина:** Xray-core в v2rayN не поддерживает протокол Hysteria 2.
- **Решение:** Для Hysteria 2 используйте **Hiddify** или **Happ**. Либо в боте переключитесь на вкладку **VLESS** и возьмите ключ `vless://`.

### 2. Запуск приложения без прав Администратора
- **Симптом:** На телефоне трафик идёт, а на ПК браузер или программы не открывают сайты, пинг `n/a`.
- **Причина:** На Windows для создания виртуального сетевого адаптера (Wintun) приложению требуются права локального администратора. Без них маршрутизация в системе не применяется.
- **Решение:** Закройте клиент полностью (включая трей возле часов) → кликните правой кнопкой мыши по ярлыку приложения → выберите **«Запуск от имени администратора»**. В свойствах ярлыка на вкладке «Совместимость» можно поставить галочку «Запускать эту программу от имени администратора» на постоянной основе.

### 3. Брандмауэр Windows (Windows Defender) заблокировал ядро
- **Симптом:** При первом запуске клиента появилось системное окно Защитника Windows, и вы нажали «Отмена» либо закрыли его.
- **Причина:** Брандмауэр заблокировал сетевые подключения для исполняемого файла ядра (`sing-box.exe` или `xray.exe`).
- **Решение:**
  1. Откройте *Параметры Windows → Обновление и безопасность → Безопасность Windows → Брандмауэр и защита сети*.
  2. Нажмите *«Разрешить работу с приложением через брандмауэр»*.
  3. Найдите в списке ваш клиент (`Hiddify`, `Happ`, `v2rayN`, `xray.exe`, `sing-box.exe`) и установите галочки для **«Частная»** и **«Общественная»** сетей.

### 4. Рассинхронизация системного времени Windows (Clock Skew)
- **Симптом:** Пинг `n/a`, в логах ошибки `handshake failed`, `certificate validity error` или `replay attack detected`.
- **Причина:** Протоколы REALITY (VLESS) и TLS/QUIC (Hysteria 2) строго проверяют временные метки. Если часы на компьютере отстают или спешат более чем на 30–60 секунд, сервер мгновенно разрывает рукопожатие. На телефонах время синхронизируется вышками связи, а на Windows батарейка BIOS или служба времени часто сбиваются.
- **Решение:**
  1. Нажмите правой кнопкой мыши на часы в правом нижнем углу Windows → **«Настроить дату и время»**.
  2. Убедитесь, что включены пункты *«Устанавливать время автоматически»* и *«Устанавливать часовой пояс автоматически»*.
  3. Нажмите кнопку **«Синхронизировать»** (Sync now).

### 5. Тип проверки пинга: ICMP Ping вместо URL Test
- **Симптом:** Нажатие кнопки «Ping» выдаёт `n/a` или таймаут, хотя сайты открываются.
- **Причина:** Обычный ping (ICMP) через прокси-протоколы не проходит, так как сервер обрабатывает только TCP и UDP потоки.
- **Решение:** Проверяйте соединение через **«Тест реальной задержки»** (Real Delay / Web Test / URL Test, по умолчанию запрос к `http://cp.cloudflare.com/generate_204` или `http://www.google.com/generate_204`). В v2rayN это шорткат `Ctrl+R`.

### 6. Блокировка UDP провайдером домашнего интернета
- **Симптом:** На телефоне через мобильный интернет (LTE) Hysteria 2 работает, а на домашнем кабельном интернете (Ростелеком, Дом.ру, МТС) на ПК — не подключается.
- **Причина:** Некоторые проводные интернет-провайдеры фильтруют нестандартный UDP/QUIC трафик на порту 443.
- **Решение:** Переключитесь на протокол **VLESS** (в меню бота: «🛡 VLESS — резерв»). VLESS работает через классический TCP с маскировкой под HTTPS/Chrome и свободно проходит через любые блокировки UDP.

## 5. В браузере работает (YouTube и др.), а Discord и Telegram на ПК НЕ работают — как исправить?

Это самая распространенная проблема на Windows при использовании прокси/VPN:

### Причина:
* Браузеры (Chrome, Edge, Яндекс, Firefox) автоматически подхватывают **Системный прокси** Windows (WinINet HTTP/HTTPS).
* **Discord** — это десктопное приложение, которое для голоса и сокетов использует протокол **UDP (WebRTC)**. Обычный системный HTTP-прокси Windows **не умеет передавать UDP-трафик**! В результате браузерная версия Discord может работать, а приложение висит на «Подключение к RTC...» или не загружается.
* **Telegram Desktop** по умолчанию игнорирует системный прокси Windows и пытается подключиться напрямую к своим серверам по IP, которые блокируются провайдерами.

### Решение:
1. **Включите «Режим TUN» (TUN Mode):**
   * В **Hiddify**: переключите режим работы внизу на **«Режим TUN»** (TUN Mode).
   * В **Happ Desktop**: включите тумблер TUN.
   * В **v2rayN**: включите переключатель **«Включить режим TUN»** (вверху/внизу окна).
   * ⚠️ **Важно:** Запускайте клиент **от имени Администратора** (правый клик → «Запуск от имени администратора»), иначе драйвер Wintun не сможет перехватить трафик системы.
2. **Для Telegram Desktop (альтернативный способ в 2 клика):**
   * Откройте Telegram Desktop → *Настройки → Продвинутые настройки → Тип подключения*.
   * Переключите на **«Использовать системный прокси»** (или выберите HTTP: хост `127.0.0.1`, порт `10809`). Telegram мгновенно подключится даже без TUN!

## 6. Работает ли «Обход РФ (Госуслуги, банки)» на ПК?

**Да, работает на всех клиентах:**

* **В Hiddify (ПК):**
  Зайдите в *Настройки (шестерёнка) → Маршрутизация → включите «Обход России (Bypass Russia)»*. Все сайты `.ru`, Сбербанк, Т-Банк и Госуслуги автоматически пойдут через ваш настоящий IP без VPN, а заблокированные ресурсы — через сервер.
* **В Happ Desktop (ПК):**
  В боте в разделе «🌐 Обход РФ» скачайте прикреплённый файл `jarvis-ru-direct-routing.json`. В Happ Desktop: *Настройки → Маршрутизация → «+»* → выберите этот файл и активируйте правило.
* **В v2rayN (ПК):**
  Внизу окна в выпадающем списке «Маршрутизация» выберите правило **«Bypass CN/RU»** (или добавьте `geosite:ru, geoip:ru -> direct`).
